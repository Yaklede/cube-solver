# Mobile PWA QA

## 목적

모바일 브라우저에서 카메라 권한, PWA 설치, 3x3 스캔 흐름, 수동 수정, 풀이 전달이 동작하는지 확인한다.

## 준비

```bash
npm run mobile:pwa
```

같은 네트워크의 모바일 기기에서 preview URL에 접속한다. 카메라 API는 HTTPS 또는 localhost 제약이 있으므로, 실제 원격 기기에서는 HTTPS 터널 또는 배포 URL을 사용한다.

## 체크리스트

- [ ] 모바일 브라우저에서 앱 첫 화면이 가로 스크롤 없이 표시된다.
- [ ] 홈 화면에서 `카메라/스캔`으로 이동할 수 있다.
- [ ] 브라우저 카메라 권한 prompt가 표시된다.
- [ ] 권한 허용 후 카메라 프리뷰가 표시된다.
- [ ] 권한 거부 시 오류 메시지가 표시된다.
- [ ] 중앙 3x3 가이드가 화면 안에 들어온다.
- [ ] `카메라에서 인식` 버튼이 현재 가이드 영역을 샘플링한다.
- [ ] 낮은 신뢰도 칸이 표시된다.
- [ ] 팔레트로 수동 수정할 수 있다.
- [ ] 기준 색상 캡처가 모바일에서 동작한다.
- [ ] 6면 저장 후 상태 문자열이 표시된다.
- [ ] 검증된 상태 문자열을 `풀이 안내로 보내기`로 전달할 수 있다.
- [ ] PWA로 홈 화면 추가 후 standalone 표시가 가능하다.

## 알려진 제약

- iOS Safari는 원격 HTTP에서 카메라를 차단한다. 배포 URL 또는 HTTPS 터널이 필요하다.
- 조명이 강하게 바뀌면 색상 보정 샘플을 다시 캡처해야 한다.
- 현재 MVP는 중앙 가이드 기반 인식이며 자동 큐브 포즈 추정은 포함하지 않는다.
